# Guide telepilote - Orange Drone Compagnon

## Role de l'application

Orange Drone Compagnon est une boite a outils installee sur la radiocommande DJI. Elle aide le telepilote a retrouver, consulter et exporter les donnees utiles apres une mission.

Elle ne remplace pas Orange Drone ni la preparation reglementaire de mission.

## Accueil

L'accueil affiche les outils principaux :

- Export logs et medias ;
- Consultation des logs ;
- Fond d'ecran ;
- Consignes internes ;
- Point d'interet ;
- Conditions de vol.

Les voyants du haut indiquent rapidement :

- dernier vol connu ;
- etat drone ;
- etat cle USB ;
- mode jour/nuit ;
- acces aux reglages et informations.

## Export logs et medias

1. Brancher la cle USB.
2. Verifier que le voyant USB est vert.
3. Ouvrir `Export logs et medias`.
4. Verifier le vol propose automatiquement.
5. Choisir un autre log si necessaire.
6. Lancer l'export.

L'application cree un dossier structure sur la cle. Les fichiers DJI originaux ne sont jamais modifies.

## Depot MSurvey

Utiliser le depot MSurvey quand il faut transmettre un log sans cle USB.

1. Ouvrir `Export logs et medias`.
2. Choisir le log concerne.
3. Appuyer sur `Deposer le log`.
4. Le formulaire MSurvey Orange s'ouvre dans l'application.

## Consultation des logs

1. Ouvrir `Consultation des logs`.
2. Chercher un log par nom ou date.
3. Ouvrir le log.
4. Consulter les informations de vol.
5. Exporter le PDF si necessaire.

## Fond d'ecran

1. Ouvrir `Fond d'ecran`.
2. Choisir RC 2 ou RC Plus 2.
3. Selectionner un modele.
4. Ajuster le QR code.
5. Exporter en JPG.

## Conditions de vol

1. Ouvrir `Conditions de vol`.
2. Choisir une ville ou la position RC.
3. Choisir le modele de drone.
4. Lire les tuiles meteo et METAR/TAF.

Cette aide ne remplace pas l'analyse reglementaire et la preparation de mission sur Orange Drone.

## Point d'interet

1. Ouvrir `Point d'interet`.
2. Choisir un ou plusieurs departements, ou une position autour de soi.
3. Exporter le KML.
4. Importer le fichier dans l’application de vol DJI.

## En cas de probleme

Aller dans `Info`, puis `Diagnostic`.

Verifier :

- dossier logs ;
- cle USB ;
- SDK DJI ;
- erreurs recentes ;
- version application.
